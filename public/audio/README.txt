THƯ MỤC LƯU TRỮ NHẠC NỀN BÀI HÁT "CRY ON MY SHOULDER" (TONE NỮ)
=============================================================

1. Tải bản nhạc hoặc bài hát cover "Cry On My Shoulder" tone nữ (định dạng .mp3).
2. Lưu file vào thư mục này với tên:
   cry-on-my-shoulder.mp3

3. Khi có file `public/audio/cry-on-my-shoulder.mp3`, website sẽ tự động phát trực tiếp file bài hát này.
   (Nếu chưa có file, website sẽ tự động phát giai điệu piano ngọt ngào tone nữ của bài hát qua Web Audio API để không bao giờ bị lỗi âm thanh).
